* Welcome to Lesson 12!

You're deep into your writing when you encounter a word that doesn't feel quite right. Do you stop, open a browser, search for synonyms, lose your flow? Not anymore! This lesson shows you how to look up definitions, find synonyms, and get translations without ever leaving Emacs.

By the end of this lesson, you'll have:
- Learned to look up Spanish definitions, online via the RAE or offline
- Installed an *offline* thesaurus so synonym lookup works with no network at all
- Seen how to run a local Wikcionario for definitions without a connection
- Discovered how to find synonyms quickly in a side window
- Understood translation integration options
- Practiced quick lookups that maintain your writing flow
- Customized dictionary tools for your workflow

*Estimated time*: 15-20 minutes

* Before You Begin

** What You Need

✓ A writing project open (any project will work)
✓ Your manuscript file open
✓ Internet connection — for the RAE dictionary, and for synonyms *until* you
  install the offline thesaurus described below

** Language Note

These tools are particularly useful for:
- *Spanish writers* using the RAE dictionary for authoritative definitions
- *Bilingual writers* switching between languages
- *English writers* using WordReference for synonyms
- *Second language writers* checking word usage and meanings

The tools work with both the English and Spanish templates in ~org-scribe~.

** Quick Check

Let's verify the dictionary module is loaded:

1. Press ~M-x~ (Alt+x or Option+x)
2. Start typing: ~org-scribe-dictionary-lookup~
3. You should see it in the completion list

If you see it, you're ready! The dictionary tools are part of the core package.

* Understanding the Available Tools

~org-scribe~ integrates three types of language tools:

** 1. Definitions (offline or online)

Definition lookup is one command, ~org-scribe-dictionary-lookup~ (~F8 F8 d~),
with two possible sources behind it:

*Online — the RAE API* (the default when nothing local is set up):
- Official dictionary of the Spanish Royal Academy
- Authoritative source for Spanish word definitions
- Etymology, multiple meanings, synonyms, antonyms, verb conjugations
- Goes through ~rae-api.com~, an unofficial service, and needs a connection

*Offline — a local Wikcionario* (needs a one-time setup, covered below):
- The Spanish Wiktionary, served from a file on your own disk
- Definitions, etymology, numbered senses with usage examples, and
  per-sense synonyms and antonyms
- Instant, and works with no network at all
- Inflected words resolve to their dictionary form (~corriendo~ → ~correr~)

*Why not an offline RAE?* There isn't one. The RAE's dictionary is
copyrighted and has never been released under a free licence — which is also
why the online lookup goes through an unofficial API rather than an official
one. Wikcionario is the offline alternative.

*Best for*:
- Spanish language writing
- Checking formal/correct usage
- Understanding word origins
- Finding synonyms and antonyms while drafting

** 2. Synonyms (offline or online)

Synonym lookup is one command, ~org-scribe-sinonimo~, with two possible
sources behind it:

*Offline — the MyThes thesaurus* (recommended, needs a one-time install):
- Reads a data file on your own disk; no network, no waiting
- The same thesaurus LibreOffice uses
- Results appear as an Org buffer with senses grouped, so you can yank a
  word straight into your manuscript
- With ~hunspell~ also installed, finds inflected words too (~corriendo~ →
  ~correr~)

*Online — WordReference* (the fallback, needs nothing):
- Web-based thesaurus rendered in a side window
- Used automatically when you have no local data, or when a word has no
  local entry
- Clickable: press ~Enter~ on a word to look /it/ up

You don't choose between them per lookup. org-scribe tries the local
thesaurus first and falls back to the web, so you always get an answer.
Installing the offline data is covered in the next section.

*Best for*:
- Finding alternative words quickly
- Avoiding repetition
- Exploring word nuances
- Browsing related vocabulary

** 3. Translation (External)

*What it is*:
- Integration with the ~gt~ package (Google Translate for Emacs)
- Not included in ~org-scribe~ but works alongside it
- Supports many languages and translation engines

*Best for*:
- Bilingual writers
- Writing in a second language
- Quick translation checks
- Multi-language projects

*Note*: Translation requires installing the separate ~gt~ package. We'll cover this at the end of the lesson.

* Using the Dictionary

Let's look up a Spanish word. The command is the same whether the definition
comes from your disk or from the RAE online — org-scribe picks the source.

** Step 1: Select or Type a Word

You have two options:

*Option A - Select a word in your text*:
1. Position your cursor on a word in your manuscript
2. Press ~M-@~ to select the word (or manually select it)

*Option B - Look up any word*:
Just have your cursor anywhere - you'll type the word when prompted.

** Step 2: Invoke the Dictionary

Press ~F8 F8~ to open the Hydra menu, then press ~d~ (for "Dictionary")

You'll see a prompt:
#+BEGIN_EXAMPLE
Palabra a buscar:
#+END_EXAMPLE

Type the Spanish word you want to look up and press ~Enter~.

*Which source answers?* With a local Wikcionario running you get that,
instantly; otherwise the RAE is queried online. To force one or the other for
a single lookup, see "Choosing a Source" at the end of this section.

** Step 3: Review the Results

A new buffer opens with the word definition formatted in Org-mode. You'll see:

#+BEGIN_EXAMPLE
#+TITLE: escribir

,* Etimología
Del lat. scribĕre.

,* Definiciones

,** 1. /verbo transitivo/
Representar las palabras o las ideas con letras u otros signos trazados en papel u otra superficie.

,*** Sinónimos: redactar, anotar, inscribir

,** 2. /verbo transitivo/
Componer libros, discursos, etc.

,*** Sinónimos: componer, crear, redactar

,** 3. /verbo intransitivo/
Comunicarse por carta con alguien.

,* Conjugaciones

INDICATIVO:
  presente:
    yo: escribo
    tú: escribes
    él: escribe
    nosotros: escribimos
    vosotros: escribís
    ellos: escriben
  ...
#+END_EXAMPLE

** What You Get

The RAE lookup provides:

1. *Etymology* (~Etimología~) - Word origin and history
2. *Definitions* - Numbered meanings with grammatical category
3. *Synonyms* (~Sinónimos~) - Alternative words for each meaning
4. *Antonyms* (~Antónimos~) - Opposite meanings (when available)
5. *Conjugations* (~Conjugaciones~) - Full verb conjugation tables (for verbs)

** Navigation Tips

The results buffer is in Org-mode, so you can:
- Press ~Tab~ on headings to fold/unfold sections
- Press ~C-c C-n~ / ~C-c C-p~ to jump between headings
- Press ~q~ to close the buffer
- Copy definitions directly to your notes

** Example: Try It Now!

Let's practice:

1. Press ~F8 F8~ then ~d~
2. Type: ~buscar~
3. Press ~Enter~
4. Explore the definitions, synonyms, and conjugations
5. Notice how the information is organized in Org-mode headings

** Word Not Found?

If the word isn't in the dictionary, you'll see a "not found" heading and a list of suggestions. Unlike the definition headings shown above (~Etimología~, ~Definiciones~, etc., which are always in Spanish - they describe the dictionary's own content), this message is one of org-scribe's own translatable UI strings, so its wording follows your ~org-scribe-message-language~ setting (default: English):

#+BEGIN_EXAMPLE
,* Word not found: buskrar

,** Suggestions:
- buscar
- busqué
- buscará
#+END_EXAMPLE

With ~(setq org-scribe-message-language 'es)~, the same lookup instead shows:

#+BEGIN_EXAMPLE
,* Palabra no encontrada: buskrar

,** Sugerencias:
- buscar
- busqué
- buscará
#+END_EXAMPLE

The API provides suggestions for similarly-spelled words. Just close this buffer and try again with a suggested word.

** Random Word Discovery

Want inspiration or to expand your vocabulary?

Press ~M-x~ and type ~org-scribe-rae-api-random~ - this fetches a random word from the RAE dictionary and displays its definition. Great for:
- Discovering new words
- Breaking writer's block
- Daily vocabulary practice
- Finding unexpected inspiration

* Installing Offline Definitions (optional, ~30 minutes)

This is the heavier of the two offline setups: a 566 MB download and a
background service. Worth it if you write without a connection; skip it
otherwise — the online RAE keeps working, and the *thesaurus* setup in the
next section is much cheaper and helps more often while drafting.

** Step 1: Install kiwix-serve

#+BEGIN_SRC sh
sudo apt install kiwix-tools      # Debian/Ubuntu
sudo dnf install kiwix-tools      # Fedora
sudo pacman -S kiwix-tools        # Arch
#+END_SRC

** Step 2: Download the Wikcionario

One file, downloaded once, from https://library.kiwix.org (search for
"Wikcionario"):

#+BEGIN_SRC sh
mkdir -p ~/zim
wget -P ~/zim https://download.kiwix.org/zim/wiktionary/wiktionary_es_all_nopic.zim
#+END_SRC

Choose the ~nopic~ flavour: it is 566 MB against 997 MB, has /more/ articles
than the ~maxi~ one (948,486), and the images it omits are of no use in a
dictionary.

** Step 3: Run the Server

*org-scribe never starts or stops this server.* It only checks whether the
server answers, and tells you if it does not. That keeps Emacs out of the
business of supervising a daemon — but it does mean you have to run it.

The tidy way is a systemd user unit, which survives reboots:

#+BEGIN_SRC conf
# ~/.config/systemd/user/kiwix-serve.service
[Unit]
Description=kiwix-serve (local Wikcionario for org-scribe)
After=network.target

[Service]
ExecStart=/usr/bin/kiwix-serve --port 8080 %h/zim/wiktionary_es_all_nopic.zim
Restart=on-failure

[Install]
WantedBy=default.target
#+END_SRC

#+BEGIN_SRC sh
systemctl --user daemon-reload
systemctl --user enable --now kiwix-serve.service
systemctl --user status kiwix-serve.service
#+END_SRC

To try it before committing to a service, just run it in a terminal:

#+BEGIN_SRC sh
kiwix-serve --port 8080 ~/zim/wiktionary_es_all_nopic.zim
#+END_SRC

** Step 4: Verify

#+BEGIN_SRC emacs-lisp
(org-scribe-wikcionario-available-p)   ;; => t
(org-scribe-wikcionario-book)          ;; => "wiktionary_es_all_nopic"
#+END_SRC

Nothing else to configure — org-scribe asks the server which book it holds.
If you run it on another port, set ~org-scribe-wikcionario-url~.

** What Changes

Same command, same key. Definitions now arrive instantly, offline, and:

- *Inflected words resolve.* Looking up ~corriendo~ opens ~correr~ and says
  so. Wikcionario does have a ~corriendo~ page, but its entire content is
  "Gerundio de correr" — following that pointer is what you wanted anyway.
- *A missing word is reported as missing*, with suggestions, rather than
  quietly going online. That distinction matters: otherwise a gap in your
  local data looks exactly like a normal network lookup.

** If You Start the Server After Emacs

Availability is checked once per session and then remembered, so lookups
cost no waiting. A server started later is therefore not noticed. Force a
fresh check with a prefix argument:

#+BEGIN_EXAMPLE
C-u F8 F8 d
#+END_EXAMPLE

or run ~M-x org-scribe-wikcionario-clear-cache~.

** Choosing a Source

#+BEGIN_SRC emacs-lisp
;; 'auto (default) — the local server when it answers, the online RAE otherwise
;; 'wikcionario    — local only; never queries the network
;; 'rae-api        — always the online RAE
(setq org-scribe-dictionary-backend 'auto)
#+END_SRC

~M-x org-scribe-rae-api-lookup~ still queries the RAE directly whenever you
want that specific source, whatever the backend setting says.

* Installing the Offline Thesaurus (10 minutes, once)

This is the single most worthwhile setup step in this lesson. Once done,
synonym lookup is instant, works on a train with no signal, and gives you
better-organized results than the web page.

** Step 1: Install the Data

The thesaurus data comes from your *operating system's* package manager, not
from Emacs. Pick your system:

#+BEGIN_SRC sh
# Debian / Ubuntu / Linux Mint
sudo apt install mythes-es

# Fedora
sudo dnf install mythes-es

# Arch / Manjaro
sudo pacman -S mythes-es
#+END_SRC

Writing in English? Install ~mythes-en-us~ instead (or as well).

*What this installs*: two data files in ~/usr/share/mythes/~, about 3 MB
total. It is the LibreOffice thesaurus, freely licensed. No Emacs package,
no configuration file, no account.

** Step 2: Install hunspell (Recommended)

You almost certainly have this already — it is what Emacs uses for spell
checking. If not:

#+BEGIN_SRC sh
sudo apt install hunspell hunspell-es      # Debian/Ubuntu
#+END_SRC

*Why it matters*: your manuscript contains ~corriendo~, ~oscurecía~,
~abandonadas~. The thesaurus is indexed under ~correr~, ~oscurecer~,
~abandonar~. hunspell is what bridges the two. Without it, looking up a
conjugated verb finds nothing — which looks like "this word has no synonyms"
rather than "this word needs its dictionary form".

** Step 3: Verify

Restart Emacs (or just evaluate the check below) and confirm:

#+BEGIN_SRC emacs-lisp
(org-scribe-mythes-available-p)   ;; => t
(org-scribe-lemma "corriendo")    ;; => "correr"
#+END_SRC

To evaluate a line: put your cursor at the end of it and press ~C-x C-e~.
The result appears in the echo area at the bottom of the screen.

If the first returns ~t~, you're done — there is nothing else to configure.

*If it returns ~nil~*: see "When It Doesn't Find the Data" at the end of
this section.

** What Changed

Nothing about how you use it. Same command, same key, same side window. The
difference is where the answer comes from:

| Situation                          | What happens                        |
|------------------------------------+-------------------------------------|
| Word is in your local thesaurus    | Instant Org buffer, no network      |
| Word is inflected (~corriendo~)      | Finds ~correr~, and tells you it did  |
| Word has no local entry            | Falls back to WordReference online  |
| No local data installed at all     | WordReference, exactly as before    |

** When It Doesn't Find the Data

Check what org-scribe sees:

#+BEGIN_SRC emacs-lisp
(org-scribe-mythes-files)   ;; => ("/usr/share/mythes/th_es_ES_v2.dat" . "...idx")
#+END_SRC

If that is ~nil~, list the directory — ~ls /usr/share/mythes/~ — and look for
a pair of files named ~th_<language>_v2.dat~ and ~th_<language>_v2.idx~.

If they live somewhere else, or are named for a different language:

#+BEGIN_SRC emacs-lisp
(setq org-scribe-mythes-directory "/usr/share/mythes/")
(setq org-scribe-mythes-language "es_ES")   ; or es_MX, en_US, ...
#+END_SRC

On Debian and Ubuntu, every regional Spanish (~es_MX~, ~es_AR~, ~es_CO~ …) is
a link to the same data, so setting your own region costs no extra download.

* Finding Synonyms

Sometimes you need alternatives quickly. One command covers both sources.

** Step 1: Invoke Synonym Search

Press ~F8 F8~ to open the Hydra menu, then press ~y~ (for "sYnonyms")

You'll see a prompt:
#+BEGIN_EXAMPLE
¿Qué palabra quieres buscar?
#+END_EXAMPLE

Type your word and press ~Enter~.

** Step 2a: Reading Offline Results

With the thesaurus installed, a side window opens showing an Org buffer:

#+BEGIN_EXAMPLE
┌────────────────────────────┬──────────────────────────────────┐
│ Your manuscript            │ *Synonyms: abandonar*            │
│                            │                                  │
│ Alex abandonó la casa.     │ #+TITLE: Synonyms: abandonar     │
│                            │                                  │
│ "abandonar" again?         │ * Sense 1 /prnl./                │
│                            │ abandonarse, dejarse llevar,     │
│                            │ confiarse, darse, entregarse     │
│                            │                                  │
│                            │ * Sense 2 /tr./                  │
│                            │ desistir, renunciar, marcharse,  │
│                            │ dejar, ceder, descuidar          │
│                            │                                  │
│                            │ * Sense 3                        │
│                            │ aparcar, posponer, retrasar      │
└────────────────────────────┴──────────────────────────────────┘
#+END_EXAMPLE

*Reading the senses*: each heading is a distinct meaning. Sense 2 above is
"to give something up"; sense 3 is "to postpone". Picking a synonym from the
wrong sense is the classic thesaurus mistake, and the grouping is there to
stop you making it.

Most Spanish entries carry no grammatical label, which is why senses are
numbered — the number is often all that separates one meaning from another.
When a label /is/ present it appears in italics (~/tr./~ = transitive verb,
~/prnl./~ = pronominal, ~/m./~ = masculine noun, ~/f./~ = feminine noun).

*It's an Org buffer*, so everything you know works: ~C-c C-n~ jumps to the
next sense, folding works, and you can copy a word with the usual keys and
yank it into your manuscript.

** Step 2b: When an Inflected Word Is Looked Up

Look up ~corriendo~ and you'll see this line under the title:

#+BEGIN_EXAMPLE
#+TITLE: Synonyms: correr

# No entry for corriendo; showing synonyms for correr
#+END_EXAMPLE

The same notice appears in the echo area. This is deliberate: you asked
about one word and are being shown another, and you should never have to
guess whether that happened. (It's an Org comment, so if you ever copy the
buffer somewhere it won't export or count toward your word total.)

A mere difference in capitalization — looking up ~Miedo~, finding ~miedo~ —
is *not* announced, because nothing meaningful was substituted.

** Step 2c: Reading Online Results

Without local data, or for a word with no local entry, the side window shows
the WordReference page instead.

#+BEGIN_EXAMPLE
┌────────────────────────────┬────────────────────┐
│ Your manuscript            │ WordReference      │
│                            │                    │
│ Alex walked to the door.   │ buscar:            │
│ Sam walked behind.         │                    │
│                            │ Synonyms:          │
│ "Walked" - need synonym!   │ - indagar          │
│                            │ - investigar       │
│                            │ - explorar         │
│                            │ - rastrear         │
│                            │                    │
└────────────────────────────┴────────────────────┘
#+END_EXAMPLE

** Navigation in Side Window

*Offline results* are a normal Org buffer:
- *Scroll*: arrow keys or ~C-n~ / ~C-p~
- *Next / previous sense*: ~C-c C-n~ / ~C-c C-p~
- *Close window*: ~q~

*Online results* are an Emacs web browser (eww):
- *Click links*: press ~Enter~ on a word to see /its/ synonyms
- *Close window*: ~q~

Either way, ~C-x }~ and ~C-x {~ adjust the width for the current session.

** Window Width Customization

By default, the synonym window is 80 characters wide. To change this:

#+BEGIN_SRC elisp
;; Add to your Emacs config
(setq org-scribe-sinonimo-window-width 100)  ; Make it wider
#+END_SRC

Adjust the number to suit your screen size and preference. This applies to
both offline and online results.

** Choosing a Source Explicitly

The default suits nearly everyone: offline when possible, online when not.
If you want to be strict about it:

#+BEGIN_SRC emacs-lisp
;; Never touch the network — a miss is reported instead of going online.
;; Good on metered connections, or when you want to know what your local
;; data actually covers.
(setq org-scribe-thesaurus-backend 'mythes)

;; Always use WordReference, even with local data installed.
(setq org-scribe-thesaurus-backend 'wordreference)

;; The default.
(setq org-scribe-thesaurus-backend 'auto)
#+END_SRC

** Language Selection

*Offline*: set the language of the thesaurus you installed —

#+BEGIN_SRC emacs-lisp
(setq org-scribe-mythes-language "en_US")   ; needs mythes-en-us installed
#+END_SRC

*Online*: WordReference's Spanish synonym site is used. For English you can
visit the English site manually — ~M-x eww~, then
~https://www.wordreference.com/synonyms/~ followed by your word.

** Example: Try It Now!

Let's find synonyms:

1. Press ~F8 F8~ then ~y~
2. Type: ~hermoso~ (beautiful)
3. Press ~Enter~
4. Browse the senses: precioso, bello, lindo, etc.
5. Press ~q~ to close the window

Now try an inflected form — ~F8 F8 y~, then ~caminaba~. If hunspell is
installed you'll get the entry for ~caminar~, with a line telling you so.

** Pro Tip: Keep It Open

You can keep the synonym window open while you write:
1. Look up a word (~F8 F8~ then ~y~)
2. Click on your manuscript window to continue writing
3. The synonym window stays visible on the right
4. Look up more words as needed
5. Close when done with ~C-x 0~ (while focused on the synonym window)

This creates a permanent "thesaurus panel" for your writing session!

* Translation Integration (Optional)

If you write in multiple languages or in a second language, translation tools can be invaluable.

** The gt Package

~org-scribe~ doesn't include translation functions, but it works seamlessly with the ~gt~ package (formerly google-translate).

** Installing gt

Add to your Emacs configuration:

#+BEGIN_SRC elisp
;; Using straight.el
(straight-use-package 'gt)

;; Or using use-package with MELPA
(use-package gt
  :ensure t
  :config
  (setq gt-default-translator
        (gt-translator
         :taker (gt-taker :text 'word :pick nil)
         :engines (list (gt-google-engine))
         :render (gt-buffer-render))))
#+END_SRC

Then restart Emacs or evaluate the configuration.

** Using gt for Translation

Once installed, you can use gt commands while writing:

*Translate word at point*:
#+BEGIN_EXAMPLE
M-x gt-do-translate
#+END_EXAMPLE

*Translate selection*:
1. Select text
2. ~M-x gt-do-translate~
3. Choose source and target languages

*Direction examples*:
- Spanish → English: Useful for checking if your Spanish prose translates clearly
- English → Spanish: Helpful when writing in Spanish but thinking in English
- Any language pair: gt supports many languages

** Quick Translation Workflow

Here's a practical workflow for bilingual writers:

1. Write a paragraph in your target language
2. Select the paragraph
3. ~M-x gt-do-translate~ to translate back to your native language
4. Check if the meaning is preserved
5. Revise original text if translation reveals awkwardness

This "back-translation" technique helps ensure clarity!

** Creating a Keybinding

To make translation faster, add a keybinding:

#+BEGIN_SRC elisp
;; Add to your config
(global-set-key (kbd "C-c t") 'gt-do-translate)
#+END_SRC

Now ~C-c t~ translates the word at point or selected text.

** Note About Performance

Translation requires an internet connection and API calls. If you're working offline:
- Use RAE dictionary (it will fail gracefully offline, but works online)
- Use local synonym lists
- Save commonly needed translations in your notes files

* Practical Workflows

Let's see how to integrate these tools into your writing process.

** Workflow 1: The Vocabulary Check

You're writing and unsure about a word:

1. Select the word in your manuscript
2. ~F8 F8~ then ~d~ - Check RAE definition
3. Review meanings - is this the right sense?
4. If not, ~F8 F8~ then ~y~ - Find synonyms
5. Pick a better word from the synonym list
6. Close the lookup windows and continue

*Time*: 30 seconds. Flow maintained!

** Workflow 2: The Repetition Fix

You've used "said" five times in one page:

1. Position cursor on the first "said"
2. ~F8 F8~ then ~y~ - Look up synonyms
3. Keep the synonym window open on the right
4. Go through each "said" in your text
5. Replace with variations: declaró, afirmó, comentó, expresó, señaló
6. Close synonym window when done

*Result*: More varied dialogue tags, more engaging prose.

** Workflow 3: The Etymology Deep Dive

You want to understand a word's deeper meaning:

1. ~F8 F8~ then ~d~ - RAE lookup
2. Read the *Etimología* section
3. Understand the word's historical roots
4. Note any related words or meanings
5. Copy interesting etymology to your notes file
6. Use the word with deeper understanding

*Benefit*: Richer, more intentional word choices.

** Workflow 4: The Bilingual Writer

You're writing in Spanish but thinking in English:

1. Think of the English word you want
2. ~M-x gt-do-translate~ - Translate to Spanish
3. See the Spanish translation
4. ~F8 F8~ then ~d~ - Check RAE definition of the Spanish word
5. Confirm it has the exact meaning you want
6. Use it in your text

*Accuracy*: Ensures you're using the right Spanish word, not just a literal translation.

** Workflow 5: The Daily Vocabulary Builder

As part of your daily writing routine:

1. ~M-x org-scribe-rae-api-random~ - Get a random word
2. Read its definition and etymology
3. Try to use it in your writing session
4. Keep a "new words" note in your project

*Growth*: Expand your vocabulary one word per day = 365 words per year!

If you use these tools frequently, create dedicated keybindings:

#+BEGIN_SRC elisp
;; Add to your Emacs config

- ~C-c d~ = Dictionary

Choose keybindings that don't conflict with your other packages!

The synonym window width can be customized:

#+BEGIN_SRC elisp
;; Narrower window (better for large screens)

Experiment to find what works for your screen!

** Offline Usage

*Synonyms*: fully offline once you install ~mythes-es~ (see "Installing the
Offline Thesaurus" above). This is the one language tool that needs nothing
from the network, and it is the one you reach for most while drafting.

*Definitions*: offline once you set up a local Wikcionario (see "Installing
Offline Definitions" above). Without that, definitions need a connection.

Note there is no free offline copy of the *RAE's own* dictionary — it is
copyrighted — so the offline path uses Wikcionario instead. If you skip that
setup, the offline thesaurus still gives you synonyms and antonyms, which
covers a good part of why writers reach for a dictionary mid-draft.

*Translation*:
- The ~gt~ package requires internet
- Alternative: install offline translation tools

For a deliberately disconnected writing session:
- Install ~mythes-es~ and ~hunspell-es~ ahead of time — that covers synonyms
  completely
- Set ~(setq org-scribe-thesaurus-backend 'mythes)~ so a miss is reported
  immediately instead of hanging on a network request that cannot succeed
- For definitions too, set up the local Wikcionario and set
  ~(setq org-scribe-dictionary-backend 'wikcionario)~
- With both in place, every language tool except translation works with the
  network unplugged
- Use built-in spell-check for basic word validation

** Language Switching

If you write in multiple languages, organize your tools:

*For Spanish*:
- ~F8 F8 d~ - RAE dictionary
- ~F8 F8 y~ - Spanish synonyms

*For English*:
- Install the ~powerthesaurus~ package, then press ~F8 F8 x~ (already bound in the hydra's Tools section — it just does nothing useful until the package is installed)
- Or manual WordReference: ~M-x eww~ → ~https://www.wordreference.com/synonyms/word~

*For Translation*:
- ~M-x gt-do-translate~ works between any language pairs

Save useful lookups for later:

1. Look up a word with ~F8 F8 d~
2. Copy the definition (select text, ~M-w~)
3. ~F8 F8 n~ - Capture a note
4. Paste the definition
5. Add your thoughts

This builds a personal vocabulary database in your project!

* Practical Exercise

Let's practice using all three tools in a realistic scenario.

** Exercise: Improve This Paragraph

Here's a sample paragraph in Spanish with some weak word choices:

#+BEGIN_EXAMPLE
María caminó hasta la puerta. Estaba triste. Dijo "adiós" con voz triste.
Juan también estaba triste. El día estaba malo.
#+END_EXAMPLE

*Problems*:
- "Triste" repeated 3 times
- "Estaba" repeated 3 times
- "Malo" is vague
- Overall vocabulary is bland

** Step 1: Fix "triste" Repetition

1. Position cursor on the first "triste"
2. ~F8 F8~ then ~y~
3. Type: ~triste~
4. Browse synonyms: melancólica, apesadumbrada, apenada, afligida, desconsolada

Replace the three instances of "triste" with variations:
- "Estaba melancólica" (she was melancholic)
- "Dijo 'adiós' con voz apesadumbrada" (with a sorrowful voice)
- "Juan también estaba afligido" (afflicted)

** Step 2: Check "melancólica" Meaning

Let's make sure "melancólica" is right:

1. ~F8 F8~ then ~d~
2. Type: ~melancólico~
3. Read definition: "Que padece melancolía, que denota o incluye este sentimiento"
4. Perfect! It fits the emotional tone we want.

** Step 3: Improve "malo"

1. ~F8 F8~ then ~y~
2. Type: ~malo~
3. Synonyms for weather context: gris, nublado, sombrío, tormentoso
4. Choose: "El día estaba sombrío" (the day was gloomy)

** Step 4: Fix "dijo" with Better Dialogue Tag

1. ~F8 F8~ then ~y~
2. Type: ~dijo~
3. Find alternatives: susurró, murmuró, pronunció
4. Choose: "Susurró 'adiós'" (whispered goodbye)

** Improved Paragraph

#+BEGIN_EXAMPLE
María caminó hasta la puerta. Estaba melancólica. Susurró "adiós"
con voz apesadumbrada. Juan también estaba afligido. El día estaba sombrío.
#+END_EXAMPLE

*Much better!* Varied vocabulary, stronger emotional tone, more evocative.

* Troubleshooting

** "RAE lookup returns error"

*Possible causes*:
- No internet connection (check your network)
- RAE API is temporarily down (try again later)
- Word contains special characters (try simplified spelling)

*Solution*: Use the synonym lookup as a backup, or check a different dictionary temporarily.

** "Synonym window too narrow/wide"

*Solution*:
#+BEGIN_SRC elisp
;; Adjust in your config
(setq org-scribe-sinonimo-window-width 80)  ; Change number as needed
#+END_SRC

Or resize manually with ~C-x }~ (grow) and ~C-x {~ (shrink).

** "Translation not working"

*Possible causes*:
- ~gt~ package not installed
- No internet connection
- Translation service blocked in your region

*Solution*:
1. Verify gt installation: ~M-x package-list-packages~, search for "gt"
2. Try manual web translation as fallback
3. Consider VPN if service is blocked

** "Too many lookups breaking my flow"

*Solution*: Change your approach:
- First draft: Write without stopping to look up words
- Second draft: Go back and improve word choice with lookups
- This maintains creative flow while still refining vocabulary
