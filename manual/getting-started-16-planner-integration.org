* Welcome to Lesson 16!

You know how to count words, track progress tables, and log your daily sessions. But do you ever wish Emacs could tell you /how many words you need to write today/ to finish your manuscript on time? That's exactly what this lesson is about.

~org-scribe-planner~ is a planning engine bundled directly inside ~org-scribe~. You give it a goal and a deadline (or a daily pace); it gives every day its own target, follows your manuscript's word count as you write, and tells you where you stand. When life gets in the way, it reshapes the days still to come — the past stays as it was.

By the end of this lesson, you'll have:
- Created a writing plan for your project, from scratch, from a preset, or for a manuscript already in progress
- Seen your word count recorded in the plan automatically
- Read your plan in its calendar, weekly summary, month grid and dashboards
- Adjusted the plan from your progress, and changed it when your plans change
- Understood how the planner counts, so its numbers never surprise you

*Estimated time*: 30-40 minutes

*Note*: This lesson covers an *optional module*. You can skip it if you prefer to track goals manually.

* Before You Begin

** What You Need

✓ ~org-scribe~ installed and working (you've completed Lessons 1-3)
✓ A project with at least a few scenes and word count properties

That's it. ~org-scribe-planner~ is bundled inside ~org-scribe~ and loads on demand the first time you run any planner command — no separate installation, no ~require~ call in your init file.

** If You Previously Used org-scribe-planner-integration

If your init file contains:

#+BEGIN_SRC emacs-lisp
(with-eval-after-load 'org-scribe-planner
  (require 'org-scribe-planner-integration))
#+END_SRC

remove that block. The integration features are built directly into the planner module, and that compatibility file no longer exists — the ~require~ would signal a file-missing error.

* What the Planner Does

| Feature                       | What happens                                                    |
|-------------------------------+-----------------------------------------------------------------|
| A goal for every day          | Each day gets its own target; together they add up exactly      |
| Word count tracking           | Every manuscript word count is recorded in the plan             |
| Past days locked              | Once a day is over, its goal never changes                      |
| Patterns, weekends, day goals | Spread the words unevenly, rest on weekends, plan special days  |
| Status                        | Ahead, on track or behind — in words, % and writing days        |
| Adjust from progress          | Re-spread the words left, or move the end date                  |
| Change the plan               | New total, length, start date, spare days… previewed first      |
| Views                         | Calendar, weekly summary, month grid, milestones, dashboards    |
| Presets                       | Novel draft, NaNoWriMo, short story… as a starting point        |
| Words written elsewhere       | Recorded and shown, never counted                               |
| Integration                   | Auto-load, mode line, agenda, health report, plan on new project |

The planner is *opt-in per project*: a project only sees it once you create a plan or enable it (see [[*Turning the Planner On and Off][Turning the Planner On and Off]]).

* Step 1: Open the Planner

Open any file of your project, press ~F8~ to open the Hydra menu, and press ~W~ for the planner submenu:

#+BEGIN_EXAMPLE
  org-scribe-planner
  ──────────────────────────────────────────────────
  p: Open project plan (load or create)
  n: New plan (fresh start)
  o: Onboard existing project
  l: Load plan
  u: Sync word count (from manuscript)
  d: Add session note
  r: Recalculate plan
  a: Adjust remaining days (keep end date)
  e: Adjust end date (keep daily words)
  c: Check progress (adjust if ahead/behind)
  m: Milestones
  w: Weekly summary
  M: Month grid
  D: Dashboards menu
  E: Enable for project
  X: Disable for project
  q: Back to main menu
#+END_EXAMPLE

** The ~p~ Key — Your Main Entry Point

~p~ (Open project plan, or ~M-x org-scribe-plan~) does the right thing for where you are:

- *Plan already active* → shows the plan calendar
- *Plan file exists but not loaded* → loads it, then shows the calendar
- *No plan yet* → asks "No writing plan found for this project. Create one?"
- *Planner disabled for this project* → offers to enable it first
- *Not in an org-scribe project* → the standard load-or-show flow

~F8 W p~ is the one command you need to remember.

* Step 2: Create Your Writing Plan

There are two ways in: ~n~ (New plan) for a plan that starts now, and ~o~ (Onboard existing project) for a manuscript already under way. Both save the plan as ~plan.org~ in your project root.

** A New Plan (~n~)

*1. Start from a preset, or from scratch.* The first question is /Start from:/. In a novel project the default answer is /Novel draft/ (80,000 words in 60 days); in a short-story project, /Short story/ (5,000 words in a week). The other presets are /NaNoWriMo/ (50,000 in 30 days), /Novella/ (30,000 in 30 days) and two daily habits (1,000 and 500 words a day).

A preset only fills in the answers. Its total and its days (or words per day) are asked with the preset's values ready: ~RET~ keeps them, any number replaces them. In a project that has a recorded total word count (asked when the project was created; see Lesson 1), that total is offered instead of the preset's, here and in the other ways of making a plan.

*2. From scratch: what do you know?* You give two of the three numbers and the planner works out the third:

#+BEGIN_EXAMPLE
Total words + Days → Calculate daily words
Total words + Daily words → Calculate days needed
Daily words + Days → Calculate total words
#+END_EXAMPLE

"Days available" are calendar days. You can type a number, or a start and an end date.

*3. Words already written.* Inside a project the planner uses your manuscript's word count. (Outside a project it simply asks how many words are already written.) These are the plan's /starting words/: they count toward the goal, never as a day's writing. Words written elsewhere are not counted — see [[*Words Written Elsewhere][Words Written Elsewhere]] below.

*4. Start date.* Today by default.

*5. Pattern and weekends.* A preset's suggested pattern and weekend setting are offered as yes/no questions — say, the short-story preset's /rising/ pattern and a goal of their own for weekends (1.5 × the daily target, which you can change). Plans from scratch are offered your defaults, if you've set any (see [[*Settings][Settings]]).

*6. Spare days.* /Do you want to set spare/break days?/ opens a small menu: add a date, a date range, all weekends, all Saturdays or all Sundays, each with an optional note ("Christmas"); remove them; list them.

After each of these the planner keeps the two numbers you gave and recalculates the third. Then it saves the plan and shows its calendar.

** A Manuscript Already in Progress (~o~)

~o~ (Onboard existing project) is for a draft that already has words:

1. It shows your manuscript's word count — 0 is fine, for an empty manuscript.
2. You give the total target and the plan's start date (today by default).
3. You set the pace: an end date (the daily target follows), or words per day (the end date follows).
4. Spare days, as above.

The words already written are the plan's starting words, so the daily target covers only what is left: a 30,000-word goal with 20,000 written, over 10 days, is 1,000 words a day. If you choose a start date in the past, the days before today get no goal.

** One Total for the Project and the Plan

The project's total word count (~F8 t~) and the plan's total are kept in step by two questions, never silently:

- Change the project's total with ~F8 t~ while a plan is active and the plan aims at a different number: you are asked whether to change the plan's total too (you then choose, as for any total change, to keep the writing days or the daily target).
- Change the plan's total with /What changed?/ → /Total words/ in a project that records a total different from the new one: you are asked whether to change the project's total too, which also rescales its acts or scenes (keeping their proportions).

Each question is asked once; answering ~n~ leaves the other side alone, and the health report then shows the mismatch. A project with no recorded total is never asked, and the planner is never loaded just to ask.

** Words Written Elsewhere

The plan counts your manuscript's prose, and only that. Words in other places — an earlier draft in another file, pages in a notebook — are not counted, so they never move a day's total or your progress.

You can still record them: ~F8 W r~ → /Words outside the manuscript/ lets you set a typed number, add a file, or stop counting one. They are kept and shown: the plan view and the health report say "Outside the manuscript: N words (not counted)". Nothing is added to the plan's records.

*Plans made before this change* counted those words. When such a plan loads, the planner subtracts them from every recorded day (so no day shows a jump) and tells you so. If your total included them, lower it with /What changed?/ → /Total words/. A file counted /on every sync/ is subtracted at its current size, so a day can differ a little if that file grew.

* Step 3: Write — the Plan Follows

** Word Counts Are Recorded Automatically

Write, then update your manuscript's word counts with ~F8 a~. The planner records the new total for today in ~plan.org~, silently: no message, no window. Several counts in one day just update today's entry.

To record on every save instead, turn on automatic word counting (requires ~org-context-extended~; it makes saves slightly slower):

#+BEGIN_SRC emacs-lisp
(setq org-scribe-auto-wordcount t)
#+END_SRC

For visible confirmation, press ~F8 W u~ (Sync word count). It reads the manuscript, records the total, reopens the calendar and prints where you stand:

#+BEGIN_EXAMPLE
Progress: 12847/80000 words (16.1%) | Ahead: +120 words (+1.2%, +0.1 writing days)
#+END_EXAMPLE

A manuscript that counts 0 words is ignored by both: an empty manuscript says nothing about what you've written.

** The Mode Line

Once today has words recorded, the mode line shows:

#+BEGIN_EXAMPLE
[W:450/650]      450 words today, against today's goal of 650
[W:300 rest]     300 words on a rest day
[W:300]          300 words on a day outside the plan
#+END_EXAMPLE

** Session Notes

Press ~F8 W d~ (Add session note) to annotate a day — "finished chapter 3", "rewrote the opening". It asks for the date (today by default), the note, and that day's word count, pre-filled with what was recorded. Change the count only when it wasn't tracked (writing on paper, in another file).

You can also type notes straight into the /Notes/ column of the Schedule table in ~plan.org~: they are read back the next time the plan loads.

~M-x org-scribe-planner-today~ logs today in one go: it reads the manuscript (or asks for today's words) and a note.

* Step 4: See Where You Stand

** The Plan Calendar

~F8 W p~ opens the plan calendar. At the top, the summary: total words, the daily target (the average, when the plan has a pattern), the weekend setting, total and working days, start and end dates, the starting words and the words elsewhere, the *status*, and the words written so far.

Below it, every day of the plan, week by week:

#+BEGIN_EXAMPLE

  2026-11-03 (Tuesday  )     1400 words     2800 words       2900 words       1500 words [107.1%] ✓
  2026-11-04 (Wednesday)     1400 words     4200 words       2900 words       0 ✗
  2026-11-05 (Thursday )     1400 words     5600 words       3800 words       900 words [64.3%] ✗
  2026-11-06 (Friday   )     1400 words     7000 words       5200 words       1400 words [100.0%] ✓

** Status: Ahead, On Track or Behind

The status reads /On track/, or /Ahead: +2000 words (+20.0%, +2.0 writing days)/, or /Behind: -500 words (-5.0%, -0.5 writing days)/. Two rules make it fair:

- *Today isn't due until it's over.* The planner compares the goals through /yesterday/ with everything you've written, /today included/: your morning never starts behind, and today's words can only help.
- *Writing days are measured along your own schedule*, day by day — a valley pattern's heavy days count as such.

It appears in the calendar summary and after every sync. ~F8 W c~ (Check progress) tells you the same, and when you're ahead or behind offers to adjust (see [[*Step 5: Adjust from Your Progress][Step 5]]).

** Milestones

~F8 W m~ shows the 25%, 50%, 75% and 100% points of your goal: the date each was reached, or the date it is expected on the current schedule, or that it can't be reached by the end date. Milestones your starting words already reach say /before the plan/.

** Dashboards

~F8 W D~ opens the dashboards menu:

- *Multi-Metric Dashboard* — everything at a glance
- *Progress Dashboard* (text, or SVG in a graphical Emacs) — overall progress, today, status, pace, streaks, and when you'll finish
- *Burndown Chart* and *Cumulative Progress* — expected against actual (gnuplot, or text)
- *Velocity Statistics*, *Velocity Chart*, *Velocity Trend Analysis* — your pace over 7, 14 and 30 days, its trend, the pace you need, and a momentum score
- *Performance Analytics* — consistency, target achievement, and your best and worst weekdays
- *Consistency Heatmap* — every day of the plan as a coloured square
- *Weekly Summary*, *Month Grid*, *Split Dashboard View*, *Show All Dashboards*

/When will I finish?/ The progress dashboard gives two answers: at your average pace and at your last week's pace, each spent on coming writing days only, and whether that lands by your end date.

* Step 5: Adjust from Your Progress

You got ahead, or fell behind. Three commands bring the plan in line with what you've actually written. All three keep the past as it was: only the days from today on change — from tomorrow, if you've already written today.

** Check Progress (~c~)

~F8 W c~ (or ~c~ in the calendar). On track, it says so. Ahead, it offers to /reduce the daily target/ (keep the end date) or /finish early/ (keep the daily target); behind, to /increase the daily target/ or /extend the deadline/. Every option shows its outcome; /keep the plan as it is/ is the default.

** Adjust Remaining Days (~a~)

~F8 W a~: keep the end date and spread the words you actually have left over the remaining writing days. It shows the change first and asks:

#+BEGIN_EXAMPLE
From 2026-11-11: 25000 words left over 20 writing days.
Daily target 1000 → 1250 words (+250, +25.0%). End date 2026-11-30 unchanged. Apply?
#+END_EXAMPLE

Afterwards the plan counts you as on track from that point. If weekends have a goal of their own, it keeps its proportion to the weekday goal.

** Adjust the End Date (~e~)

~F8 W e~: the opposite trade. Keep your daily target and move the end date so the words left fit — earlier when you're ahead, later when you're behind. Rest days are skipped.

#+BEGIN_EXAMPLE
Daily target 1000 words kept. Writing days 30 → 35.
End date 2026-11-30 → 2026-12-05: extended by 5 days. Apply?
#+END_EXAMPLE

* Step 6: Change the Plan

When the plan itself changes — a new deadline, a holiday, a different goal — press ~F8 W r~ (or ~r~ in the calendar). It asks /What changed?/:

| Choice                        | What it does                                                                        |
|-------------------------------+-------------------------------------------------------------------------------------|
| Total words                   | A new goal; then keep the writing days (daily target follows) or the daily target (end date moves) |
| Daily words                   | A new pace; then keep the total (end date moves) or the writing days (total follows) |
| Days available                | A new length; then keep the total (daily target follows) or the daily target (total follows) |
| Two values (third calculated) | Set two of total, daily words and days                                             |
| Start date                    | Move the plan earlier or later                                                      |
| Words outside the manuscript  | See [[*Words Written Elsewhere][Words Written Elsewhere]]                                     |
| Writing pattern               | How the words are spread over the days                                             |
| Weekends                      | Same as other days, a goal of their own, or no writing                             |
| Day goal: set / remove / clear | A goal for one particular day                                                     |
| Add, remove or clear spare days | Days off                                                                         |

Every option is tried on a copy first and shown with its outcome — /ends 2026-12-01, 1000 words/day, total 30000 words/ — so you choose knowing the result. The first option is the default, and ~C-g~ at any question leaves the plan untouched. Past days keep their goals whatever you choose.

** Spare Days, Weekends and Day Goals

Adding or removing spare days, changing the weekend setting, or setting a day goal changes how many words some days take. The planner then asks how the plan should absorb it:

- *Keep the end date* — the daily target changes (the default)
- *Move the end date* — keep the daily target
- *Keep the end date and the daily target* — the total changes

*Weekends* can be the same as other days, have a goal of their own (more words on Saturdays and Sundays, or fewer), or be days off. You also choose which days are the weekend — Friday and Saturday works too.

*A day goal* gives one date its own target: more on a free day, fewer on a busy one, 0 to make it a rest day. It can't be set on past days, outside the plan, on spare days, or on weekends that are already days off — the planner tells you why.

** Writing Patterns

A pattern spreads the words unevenly over the writing days, each /mild/, /moderate/ or /extreme/:

| Pattern   | Shape                                           |
|-----------+-------------------------------------------------|
| Steady    | The same goal every day                         |
| Valley    | Start high, ease off in the middle, finish high |
| Mountain  | Start easy, peak in the middle, ease at the end |
| Rising    | Goals grow over time                            |
| Declining | Goals shrink over time                          |
| Random    | Varied goals within a range                     |

Changing the pattern reshapes only the days still to come. The random pattern keeps its own seed, so its goals stay the same from one session to the next.

** Moving the Start Date

/Start date/ moves the plan earlier or later. It keeps the number of writing days, so the end date moves too. Spare days and day goals from today on can stay on their dates (the default — the question lists any that would fall outside the plan) or move with the start; past ones never move, and neither do the words you've written.

Before applying, it warns you about written words that would end up outside the plan, past days that would join it (they're locked as they are), and past days left outside. A plan already under way is recalculated so its remaining days cover the words left.

* How the Planner Counts

A few rules explain every number you'll see.

** Every Day Has Its Own Goal

The plan gives each day a goal in whole words, and the goals add up exactly to your total: 10,000 words over 7 days is 1,429 four times and 1,428 three times. Fixed days (rest days, weekend goals of their own, day goals, past days) keep their goals; the other days share the rest, shaped by the pattern. The /daily target/ shown is the goal of an ordinary day.

** The Plan's Length Is Its Writing Days

The plan stores how many /writing days/ it has; the end date follows from them and the spare days. That's why adding a spare day can either push the end date out or keep it, as you choose.

** Past Days Are Locked

Once a day is over, its goal never changes again — not with a new total, a new pattern, new spare days or a recalculation. Your history stays honest, and changes only ever reshape the days to come.

** Rest Days

A rest day is any day whose goal is 0: a spare day, a weekend off, a day goal of 0. Rest days never count as missed, don't break your streak, and are left out of your pace. Writing on one still counts.

** Starting Words

Words written before the plan — in the manuscript, or declared as written elsewhere — are the plan's /starting words/. They count toward the goal and the completion percentage, but they're never one day's writing: your pace, streaks and best day reflect only what you write during the plan.

** Pace, Days and Statuses

- Your *pace* is the words written during the plan divided by your writing days so far — /missed days count, with 0 words/; rest days don't.
- A day is *met* at its goal, *partial* from 75%, *missed* below that or with nothing — and also when the manuscript ended the day shorter than it started (you cut more than you wrote). Today is never missed while it's under way.
- *Best and worst day* only look at days you wrote on.
- The *estimated finish* spends your pace on coming writing days, skipping rest days.

The heatmap, the achievement rate, the weekly summary and the calendar's ✓ ~ ✗ marks all use these rules.

* The Plan File

~plan.org~ is an ordinary Org file:

#+BEGIN_EXAMPLE
,* My Novel
:PROPERTIES:
:TOTAL_WORDS: 80000
:DAILY_WORDS: 1177
:DAYS:     70
:START_DATE: 2026-10-12
:END_DATE: 2026-12-20
:CURRENT_WORDS: 8214
:PREEXISTING_WORDS: 3672
:WRITING_DAYS: 62
:SPARE_DAYS: 2026-10-18,2026-10-25
:DAILY_WORD_COUNTS: 2026-10-12:8214
:END:

,** Schedule

|       Date | Target | Planned total | Actual total | Actual | Progress % | Notes            |
|------------+--------+---------------+--------------+--------+------------+------------------|
| 2026-10-12 |   1177 |          4849 |         8214 |   4542 |     385.9% |                  |
| 2026-10-18 |   REST |         10734 |              |        |            | Sundays are free |
#+END_EXAMPLE

The main properties:

| Property              | Meaning                                                              |
|-----------------------+----------------------------------------------------------------------|
| ~TOTAL_WORDS~           | Your goal, starting words included                                  |
| ~WRITING_DAYS~          | The plan's length in writing days                                    |
| ~START_DATE~, ~END_DATE~  | The plan's window (the end date follows from the writing days)       |
| ~DAYS~                  | Calendar days from start to end, rest days included                 |
| ~DAILY_WORDS~           | The goal of an ordinary day                                          |
| ~CURRENT_WORDS~         | Words written so far, starting words included                        |
| ~PREEXISTING_WORDS~     | The starting words                                                   |
| ~DAILY_WORD_COUNTS~     | The record: the total written by the end of each day                 |
| ~SPARE_DAYS~            | Days off                                                             |

Others appear when you use the features they belong to: ~LOCKED_GOALS~ (past days' goals), ~SCHEDULE_ADJUSTMENT~ (set by an adjustment from progress), ~PATTERN~ and ~PATTERN_CONFIG~, ~WEEKEND_MODE~, ~WEEKEND_DAYS~ and ~WEEKEND_DAILY~, ~CUSTOM_GOALS~ (day goals), ~OUTSIDE_WORDS~ and ~OUTSIDE_FILES~ (words written elsewhere).

Prefer the planner's commands to editing the properties by hand: the commands keep them consistent. The Notes column is the exception — type there freely.

Plans saved by earlier versions load as they are: their writing days are worked out from their dates, and a daily target set by an old recalculation is kept.

* Settings

** New Plans

#+BEGIN_SRC emacs-lisp
;; Offered to plans made from scratch (only asked when not steady / ordinary weekends)
(setq org-scribe-planner-default-pattern 'valley           ; flat, valley, mountain, rising, declining, random
      org-scribe-planner-default-pattern-intensity 'mild   ; mild, moderate, extreme
      org-scribe-planner-default-weekend-mode 'rest        ; same, different, rest
      org-scribe-planner-default-weekend-days '(6 0)       ; 0 = Sunday … 6 = Saturday
      org-scribe-planner-default-weekend-daily nil)        ; nil: 1.5 × the daily target
#+END_SRC

The presets are a customizable list: ~M-x customize-variable RET org-scribe-planner-presets~. Each has a name, a description, a total, days or words per day, a suggested pattern and weekend setting, and the project types it's the default for.

** Views and Tracking

#+BEGIN_SRC emacs-lisp
(setq org-scribe-planner-week-start-day 0)      ; weeks from Sunday (default 1, Monday)
(setq org-scribe-planner-streak-grace-days 2)   ; a streak survives logging the morning after
#+END_SRC

** The Agenda

~M-x org-scribe-planner-sync-agenda~ adds a /Write N words/ TODO for every writing day of the plan to ~plan.org~ and adds the file to your agenda. Once synced, the entries are regenerated whenever the plan changes; rest days get none.

** Turning the Planner On and Off

A project's choice lives in its ~.org-scribe-project~ file as ~# Planner: yes~ or ~# Planner: no~. Creating a plan turns it on. ~F8 W E~ / ~F8 W X~ (or ~M-x org-scribe-planner-enable-for-project~ / ~-disable-for-project~) flip it. In a project that declined, ~F8 W~ offers to enable it instead of showing the menu. Projects created before this choice existed behave as /yes/.

When you create a project (~org-scribe-create-novel-project~ or ~org-scribe-create-short-story-project~), the planner offers to create a plan right away. Answering /no/ records ~# Planner: no~ so you aren't asked again.

** How Auto-Loading Works

When you open a file of a project, the planner looks for its plan:

0. [@0] The path cached in ~.org-scribe-project~ as ~# Plan:~ (written after the first load — fastest)
1. ~<project-root>/plan.org~
2. ~<project-root>/<project-title>-plan.org~
3. Any ~.org~ file in the project root with a ~TOTAL_WORDS~ property

If one is found the plan loads silently (/org-scribe-planner: loaded plan "My Novel"./); if not, nothing happens. Switching to another project's files switches to its plan.

** Disabling Individual Features

Each automatic feature can be turned off. Set these *before* the planner first loads (e.g. in ~early-init.el~):

* Practical Exercise

Let's do a complete plan-write-review cycle.

** Exercise: Your First Planned Week

1. *Create a plan* — open your project, press ~F8 W p~, answer /yes/, and start from the preset offered. Accept its values with ~RET~.
2. *Take weekends off* — ~F8 W r~ → /Weekends/ → /No writing/ → keep the end date. Look at the preview: the daily target goes up.
3. *Write* — ~F8 m~ for writing mode, write a few hundred words, save.
4. *Count* — ~F8 a~. Check the mode line: ~[W:words/goal]~.
5. *Annotate* — ~F8 W d~ and write what you did.
6. *Check* — ~F8 W c~. Ahead? Try the /finish early/ preview, and press ~C-g~ to leave the plan as it is.
7. *Look around* — ~F8 W M~ for the month grid, ~F8 W D~ for the dashboards.

Come back tomorrow: yesterday's goal is now locked, and today's status measures you through yesterday.

* Common Questions

** "The plan says I'm behind by exactly the words I'd already written."

The words you'd already written probably aren't in the manuscript, and the plan counts the manuscript only. Lower the total by those words (/What changed?/ → /Total words/), or paste them into the manuscript. See [[*Words Written Elsewhere][Words Written Elsewhere]].

** "I changed the total and my past days didn't change."

That's by design: past days are locked. Only the days to come take the new goal.

** "The mode line shows nothing, or [W:0/650], even though I wrote today."

The mode line appears once today has words recorded. Run ~F8 a~ (or ~F8 W u~). If the words were written elsewhere (on paper, another file), record them with ~F8 W d~.

** "Why is my daily target 1,429 and not 1,500?"

Goals add up exactly to your total. 10,000 words at up to 1,500 a day takes 7 days, and 7 days of 1,429 (some 1,428) make exactly 10,000.

** "I set a day goal and the plan asked how to adjust."

A day goal changes how many words that day takes; the others must absorb the difference — over the same dates (the daily target changes), over more or fewer days (the end date moves), or by changing the total. Each option shows its outcome.

** "Can I use this with a short story project?"

Yes. The planner works the same way in short-story projects; the /Short story/ preset is offered first.

** "I want to track several projects."

Each project has its own ~plan.org~. Open a file of another project and the planner switches to that project's plan.

* Troubleshooting

** "W in the Hydra does nothing."

- Confirm hydra is installed: ~M-: (featurep 'hydra) RET~.
- Load the planner by running ~M-x org-scribe-plan~ once.

** "The plan doesn't auto-load even though plan.org exists."

- Confirm you're inside an org-scribe project (the directory has a ~.org-scribe-project~ file) and the project hasn't declined the planner (~# Planner: no~).
- Confirm ~org-scribe-mode~ is active in the buffer.
- Confirm ~org-scribe-planner-auto-load-plan~ is ~t~, or load it by hand: ~M-x org-scribe-planner-load-plan~.

** "Word counts don't reach the plan after F8 a."

- A plan must be active: ~F8 W p~ loads it.
- Confirm ~org-scribe-planner-auto-push-wordcount~ and ~org-scribe-planner-auto-track-daily~ are ~t~.
- An empty manuscript (0 words) is ignored on purpose.
- Run ~F8 W u~ to sync by hand and see the result.

** "I get an error loading org-scribe-planner-integration."

Your init file still contains ~(require 'org-scribe-planner-integration)~. Remove it — the integration is built into the planner.
